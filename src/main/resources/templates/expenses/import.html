File format

The first row names the columns. Column order doesn't matter, and extra columns are ignored.

  • title (or description): required
  • amount: required, greater than 0, e.g. 85 or 1,250.50
  • date: required, 2026-10-31 or 31/10/2026
  • category: optional; if empty it's guessed from the title, otherwise Other
  • note: optional

A file from Export CSV imports back as-is. Every row is checked first, and nothing is saved unless all rows are valid. Up to 2,000 rows and 1 MB per file.
